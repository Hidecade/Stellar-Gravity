# Stellar Gravity 🪐

**Stellar Gravity** は、重力と天体の進化をテーマにした、Matter.js 物理エンジン搭載のスタイリッシュ・グラビティパズルです。

宇宙の静寂を感じさせるミニマルなデザインと、心地よい物理挙動をブラウザでそのまま体験できます。

---

## 🎮 ゲーム概要

* **コアへの射出**: 自動回転するランチャーから、中心の恒星に向けて惑星をショットします。
* **合体と進化**: 同じ天体同士をぶつけると、より巨大な天体へ進化（全9段階）。
* **コンボシステム**: 連続して合体させるとボーナススコアが発生。白く輝く星屑が舞うエフェクトが爽快感を高めます。
* **重力崩壊**: 最終進化「Black Hole」に到達すればステージクリア。コアが超新星爆発を起こし、次の星系へ移行します。
* **タイムリミット（焦燥感）**: ステージが進むごとにショットの制限時間が短くなります。時間切れになると強制射出されるため、瞬時の判断と正確なエイムが求められます。
* **デッドライン**: 惑星がレッドゾーン（境界線）を一定時間超え続けると重力均衡が崩れ、**GAME OVER** となります。

---

## 🌐 オンライン＆拡張機能

* **WORLD RANKING（世界ランキング）**: Firebaseを利用したオンラインスコアボードを搭載。ゲームオーバー時に自分の推定順位がリアルタイムで算出され、世界中のプレイヤーとスコアを競うことができます。
* **SOUNDTRACK モード**: タイトル画面から、各ステージの美しいアンビエントBGMをフルサイズで試聴できる専用モードを備えています。

## 🕹 操作方法

### 惑星の射出
* **PC**: `ENTER` または `↑ (上矢印)` キー、もしくはプレイエリア（UIボタン外）をクリック
* **Mobile**: プレイエリア（UIボタン外）をタップ

### BOOST（加速・偏向）
* **PC**: `SPACE` キーをホールド
* **Mobile**: 画面左下の **BOOST** ボタンをホールド
* ランチャーの回転速度が劇的にアップし、射出時に強力な横方向のドリフト（遠心力）を加えることができます。

### ユーティリティ
* **PAUSE / TITLE**: ゲーム中、右下の「PAUSE」ボタンから一時停止が可能。ポーズメニューから「TITLE」を選択することで、現在のスコアを破棄して即座にタイトル画面へ戻ることができます。

## ✨ 視覚・演出効果

* **ミニマリズム**: 白とネオンカラー（シアン・紫など）を基調とした、清潔感のある洗練されたUIとタイポグラフィ。
* **グローエフェクト**: 天体やパーティクルが幻想的に光り輝く、宇宙空間を意識した高品位な光彩演出。
* **スマートフィードバック**: コンボ発生時には加算スコアが優雅に浮遊し、星屑（パーティクル）となって霧散します。

---

## 🔊 サウンドについて

* 没入感を高めるアンビエントなBGMと、重厚な合体効果音・ブラックホール爆縮音。
* タイトル画面で **BGM ON / OFF** の切替が可能（設定はブラウザにローカル保存されます）。
* **⚠ iPhone / Safari ユーザーの方へ**: ブラウザの仕様上、最初の「START」タップ時、または画面タップ時にオーディオが自動的にアンロックされます。
